# Security Policy

## Reporting a security issue

Please do not publish security vulnerabilities, credentials, private user data, or exploit details in a public issue.

Preferred reporting path:
1. Use GitHub Private Vulnerability Reporting if it is enabled for this repository.
2. If private reporting is unavailable, use a private contact method listed on the official GoPilot product presence.

## Repository scope

This repository is a public showcase and documentation repository. The production GoPilot application source code is not hosted here.

## Sensitive information

Never attach:
- API keys or tokens
- signing material
- private permit documents
- customer or driver PII
- invoices or payment data
- private logs
- production configuration

## Public issue safety

For ordinary bug reports:
- use example data
- redact screenshots
- remove permit/customer identifiers
- do not include credentials
- do not post private account information
