# Privacy Overview

This document is a public project overview, not a replacement for the official privacy disclosures distributed with GoPilot.

GoPilot is designed around driver-controlled trip organization. Features may work with trip details, permit images/documents, OCR text, route notes, mileage, receipts, invoices, documents, and other records the user chooses to create.

The public repository must never contain real user data.

When sharing screenshots or bug reports, users should remove:
- personal names
- phone numbers
- addresses
- permit/customer identifiers
- VIN or equipment identifiers when sensitive
- receipts and payment information
- invoices
- location history
- notification content

For authoritative privacy terms, use the privacy information distributed through the official app/store listing.
