# Screenshot Guidelines

Screenshots can make the repository much stronger, but they must be safe for a public repository.

## Approved screenshots should show

Good examples:
- empty/new Saved Trip
- sample/demo Permit Reader data
- Trip Command Center with fake data
- settings/about screens without account details
- feature navigation
- demo invoice or mileage screens with fictional values

## Redact before publishing

Remove or replace:
- real permit numbers
- customer names
- driver names when private
- phone numbers
- addresses
- emails
- VINs
- unit/trailer identifiers when sensitive
- invoice/customer details
- payment information
- real receipt details
- GPS/location history
- notification text
- device identifiers
- debug banners/logs
- API keys/tokens

## Use fictional data

Recommended demo values:
- Driver: Demo Driver
- Customer: Example Logistics
- Trip: Demo Trip 001
- Permit: DEMO-0001
- Origin: Sample City, TX
- Destination: Example City, OK

Never publish a real permit just to demonstrate OCR.
