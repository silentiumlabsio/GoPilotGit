# FAQ

## Is the GoPilot source code public?
No. This repository is a public product showcase and documentation repository.

## Why keep the source private?
GoPilot is a commercial mobile application. Source, release infrastructure, signing configuration, and implementation details remain private.

## Does GoPilot replace an official permit?
No. GoPilot helps organize and review permit information. Drivers must compare extracted information with the official permit and current requirements.

## Who is GoPilot for?
GoPilot is designed broadly for truckers, hotshot drivers, owner-operators, small fleets, and pilot/escort workflows.

## Does GoPilot support iPhone?
iOS is in progress. This repository should not claim an iPhone release until it is actually available.

## Can I report bugs here?
Yes, as long as the report does not include private trip/customer data, credentials, or sensitive documents.

## Should I upload my permit to a GitHub issue?
No. Use fictional or heavily redacted examples.
