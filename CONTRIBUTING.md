# Contributing

This is a public documentation/showcase repository. The GoPilot application source is private.

Useful contributions include:
- documentation corrections
- accessibility suggestions
- public feature-request discussions
- typo fixes
- improvements to screenshot redaction guidance

Do not submit:
- proprietary app source
- reverse-engineered source
- credentials
- private documents
- customer data
- private vulnerability details in a public issue

Security reports should follow `SECURITY.md`.
